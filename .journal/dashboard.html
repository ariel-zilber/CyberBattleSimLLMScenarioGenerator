Strongest verified evidence

Runtime: firewall over-permission

An actual generated SSH edge crossed 10.1.10.0/24 → 10.0.1.0/24 without the exact subnet rule pair. With valid Connect state, the improved actuator returned LateralMove and owned the target.

Runtime: firewall blocking

A generated credential edge missing its source outgoing port rule returned reward -10, no outcome, and target privilege 0. The static evaluator nevertheless included the same edge.

Component: goal-policy drift

Production-nested settings requested strategy value, promotion disabled, and a shared tag. GoalNormalizer used diverse, promotion enabled, and no shared tag.

Runtime adapter: missing Admin gate

The experimental object fixture executed System escalation directly at User. The earlier numeric 9→8 claim was wrong: compiled initial discovery added one action, so the tested sequence still contained 9 actions.

Artifact: nondeterministic generation

Same numeric seed 4242 under different PYTHONHASHSEED values produced different generated placements. The object MVP also emitted different SHA-256 values for identical input.

Artifact: credential-bound mismatch

A real 778-node xlarge artifact contains 1,554 unique credentials and one action holding 1,552. Evaluator observation high is 1,000; loaded model denominator is 100. Cache loss has not been observed.

Held-out success peaks at 96% around episode 4,000. By episode 8,000 it is 90%, invalid actions rise from 40.9% to 62.8%, and productive-action rank worsens from 7.42 to 13.94. Longer training is not improving every metric, but performance remains far above the 8–12% random baseline.
