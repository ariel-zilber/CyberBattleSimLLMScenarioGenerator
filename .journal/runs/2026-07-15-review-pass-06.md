# Review Pass 06 — Static Gates

## Finding

The early post-generation audit is a fast filesystem/text contract, not a final
data-validity gate. Its current invocation omits all optional strict/final checks.

## Interaction with other defects

This would be acceptable if runtime evaluation were a hard, freshness-checked
gate. It is currently not: nonzero evaluator exits are treated as partial solve
and old metrics can be aggregated. Consequently malformed or causally invalid
data can move through both layers without a clean authoritative failure.
