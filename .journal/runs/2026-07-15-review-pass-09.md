# Review Pass 09 — Coverage Meaning

## Conclusion

The fixed coverage tools now agree better on textual slot extraction, but the
pipeline still does not measure whether specialist actions are reachable or
usable. Runtime “slot coverage” is also a static node-key count and silently skips
unparseable files.

This explains how 100% reported slot coverage can coexist with BFS failures,
masked System actions, and invalid training data.
