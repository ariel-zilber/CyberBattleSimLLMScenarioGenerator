# Review Pass 07 — Generation Mutation Semantics

## Paths compared

- `pipeline/phase2/dataset.py` removes a pending slot before each outer attempt.
- `pipeline/phase2/generator.py`, which is used by the main pipeline, does not.
- `cli.generate_scenario` creates required subdirectories but does not clear old
  files.

## Conclusion

The safer cleanup behavior in the dataset builder does not protect the main
fixed-scale pipeline. Normal reruns and internal `--require-solvable` retries can
produce hybrid directories containing files from multiple seeds.
